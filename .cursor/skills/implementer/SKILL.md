# Implementer

1. Read `AGENTS.md`, `.agent/decisions.md`, `.agent/constraints.md`.
2. If the request is ambiguous (file, API, behavior, visual), ask once. Do not guess.
3. Do exactly the requested volume. No extra refactors, no new dependencies unless asked.
4. Stay inside the current stage in `docs/PROGRESS.md` unless the user is doing harness/git/tooling.
5. Verify with `.agent/verification.md`.
6. Append one short entry to `.agent/observability.md`: was → did → checked → is now.
7. Report in Russian, in the format in `.agent/context.md`.
