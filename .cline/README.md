# `.clibne/` — рабочие заметки агента

Служебная папка. К продукту и к коду проекта не относится: здесь лежит контекст, по которому работает агент-исполнитель.

## Владение

- Проект **Open Music Player** ведут **пользователь** (постановщик, владелец решений) и **Cursor**.
- Агент (Cline) — **исполнитель**: boilerplate и инженерная рутина. Код и файлы проекта меняет **только по прямому запросу**; при неоднозначном ТЗ — уточняет, а не догадывается.
- Заметки проекта в `docs/` агент не ведёт.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `context.md` | Роль, режим работы, стек, конвенции, формат отчёта |
| `project-plan.md` | План курса (этапы 1–17), текущий этап, его DoD |
| `verification.md` | Проверки-доказательства: команды и критерии |
| `constraints.md` | Ограничения: что агент не читает и не меняет без запроса |
| `observability.md` | Журнал: как было → что сделал → что произошло → как есть сейчас |

## Рабочий цикл

1. Прочитать `context.md`, `constraints.md` и последнюю запись `observability.md`.
2. Сверить задачу с `project-plan.md` (этап, зона ответственности).
3. Если ТЗ неоднозначно — уточнить до правок.
4. Выполнить только заявленный объём.
5. Проверить по `verification.md`.
6. Дописать запись в `observability.md`.
